# Exercício 01 - Casos de Teste BDD para Login

## Objetivo

Praticar a criação de casos de teste utilizando a metodologia BDD (Behavior Driven Development), transformando requisitos funcionais em cenários de teste escritos no formato Gherkin.

## Cenário Proposto

Foi disponibilizada uma lista de requisitos para uma funcionalidade de login contendo regras de negócio, validações e comportamentos esperados do sistema.

A partir desses requisitos, foram elaborados cenários de teste para validar o funcionamento da funcionalidade.

## Requisitos Testados

- Login com credenciais válidas
- Login com usuário inválido
- Login com senha inválida
- Validação de campos obrigatórios
- Bloqueio da conta após múltiplas tentativas inválidas
- Regras de validação de senha

## Técnicas Aplicadas

- BDD (Behavior Driven Development)
- Escrita de cenários utilizando Gherkin
- Identificação de fluxos positivos e negativos
- Análise de requisitos
- Cobertura de regras de negócio

## Estrutura Utilizada

Os cenários foram escritos utilizando o padrão:

```gherkin
Dado que...
Quando...
Então...
```

## Aprendizados

Durante o exercício foi possível praticar:

- Interpretação de requisitos
- Transformação de requisitos em cenários de teste
- Identificação de casos positivos e negativos
- Organização de testes utilizando BDD
- Escrita de testes com foco no comportamento do usuário

> Exercício realizado durante meus estudos de Qualidade de Software (QA) com foco em BDD e análise de requisitos.
